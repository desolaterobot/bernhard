# AI Research Assistant by Bernhard's Apprentices

Research papers are powerful sources of knowledge, but they’re often dense, time-consuming, and difficult to digest. We created an AI research assistant that helps students and researchers cut through the complexity by summarizing papers, answering questions, and turning insights into structured notes or reports.

## Running steps for streamlit app:
1. Install dependencies.
```
pip install -r requirements.txt
```
2. Setup .env file with AWS model access keys
3. Run the streamlit app as localhost.
```
streamlit run app_agent.py
```
